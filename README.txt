PLATAFORMA PARA MANUTENÇÃO DO ENTRE AMIGOS - ETAPA 3

Como usar:
1. Extraia o ZIP.
2. Abra index.html no Chrome.
3. Use o filtro Loja atual.
4. Troque o perfil no topo para testar permissões.

Incluído:
- Layout do dashboard aprovado
- 5 lojas oficiais
- Cadastro de setores
- Cadastro de áreas
- Cadastro de equipamentos sem valor do ativo
- Regras de acesso ADMIN/DIRETOR
- Preventivas com calendário


ETAPA 4:
- Abertura de OS com campo para anexar foto ou vídeo.
- Fotos aparecem com pré-visualização.
- Vídeos ficam registrados pelo nome do arquivo na versão local.
- Status oficiais da OS:
  Aberta, Em execução, Aguardando peça, Aguardando terceirizada, Aguardando aprovação, Concluída.
- Status pode ser alterado diretamente no cartão da OS.


ETAPA 4.1 VERIFICADA:

- O campo "Foto ou vídeo do problema" está destacado em laranja.
- Status disponíveis: ABERTA, EM_EXECUCAO, AGUARDANDO_PECA, AGUARDANDO_TERCEIRIZADA, AGUARDANDO_APROVACAO, CONCLUIDA.

- Indicadores de execução e atraso.
- Tela Equipamento 360º com ficha técnica, OS, custos, próxima preventiva e anexos.
- Custos separados na OS: material, serviço terceiro e mão de obra interna.

- Preventiva terceirizada leva custo extra para a OS preventiva gerada.
